# Portfolio Exposure Analyzer

Tool for analyzing portfolio exposure and overlap across stocks, funds and ETFs.

## Git Commands

Check changes:
```bash
git status
```

Add all changes:
```bash
git add .
```

Commit:
```bash
git commit -m "message"
```

Get latest changes:
```bash
git pull
```

Push to GitHub:
```bash
git push
```

View commit history:
```bash
git log --oneline
```

## Normal workflow

```bash
git add .
git commit -m "message"
git pull
git push
```
